# module-spec-files.md

This module describes the structure of module specification documents described in markdown format. No python implementation is required for this module.

Module specification documents have a name like `module-name.md`, and a top level heading like `# module_name.py`, which describes where the module is implemented.

Some modules are documentation only - i.e. are not intended to be compiled into code. These modules can be identified by the fact the top-level title is the name of the spec document, e.g. `# module-name.md`.

Each module requiring an implementation will have its implementation file created in a `tlc` directory adjacent to the spec file. For example, a spec at `path/to/module-name.md` with title `# module_name.py` will be implemented at `path/to/tlc/module_name.py`.

Typical folder structure would be:

```
package/
    module-1.md
    tlc/
        module_1.py
        module-1-intermediate.md
    module-2.md
    tlc/
        module_2.py
    sub-package/
        module-3.md
        tlc/
            module_3.py
```

The `tlc` directories will be generated by the compiler adjacent to each spec file, and will contain the intermediate spec files and implementation files for that spec.
